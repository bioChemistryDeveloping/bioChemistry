break

В конце каждого скрипта должен находиться break: без него компилятор не поймёт, где скрипт заканчивается. Также с его помощью можно завершить скрипт раньше, чем закончится сам код.

Цвет

Чтобы задать клетке цвет, используйте название цвета и значение от 0 до 255 (unsigned byte).

red 100;
green 150;
blue 50;
break;

Переменные

Команды такого типа называются функциями, и они могут использовать изменяемые данные. Для этого укажите тип данных, название и значение.

byte a 80;
byte b 20;
red a;
green a;
blue b;
break;

В этом примере создаются две переменные со значениями 80 и 20, после чего они используются в цветах клетки.

Типы данных

Существует три типа данных: byte, int и float. Каждый подходит для своих задач: например, byte нужен для цветов, потому что их функции воспринимают только этот тип.

byte хранит 2^8 значений, int хранит 2^32 значений. float хранит столько же, сколько int, но, в отличие от byte и int, не является целочисленным, поэтому может хранить дробные числа.

Изменение значений

Значения созданных переменных можно менять в реальном времени.

byte a 0;
a a + 1;
red a;
break;

В примере выше значение задаётся на ходу через вычисление «a a + 1». Оно означает, что a (первое значение) = a + 1.

Вычисления

Можно создавать более сложные вычисления, используя «-», «+», «/» и «*».

byte v 10;
byte v2 10;
byte v3 20;
byte r 0;
r v * v2 - v3;
red r;
break;

Условия

Чтобы создать условие, используйте операторы «==», «<», «!=» и числа.

int a 50;
if a < 100 {
  red 0;
  green 0;
  blue 0;
}
break;

Этот пример сделает клетку тёмной, если условие a < 100 верно. Оператор «==» проверяет, совпадают ли значения, а «!=» проверяет, что они не совпадают.

Деление

Теперь, когда у вас есть основа логики клетки, вы можете заставить её делиться и выполнять другие действия. Для деления используйте split.

«split 0» делит клетку на две.
«split 1» делит её на две скреплённые части.

heirdom

При делении клетка обнуляет все изменяемые значения (переменные). Чтобы этого не происходило, добавьте heirdom после инициализации.

«heirdom 0» передаёт значения первой клетке-потомку (то есть при делении значение будет храниться только в одной из двух клеток).
«heirdom 1» делает то же самое, но для второго потомка.
«heirdom 2» передаёт значения обоим потомкам.

byte s 0 heirdom 2;
if s < 3 {
  s s + 1;
  split 1;
}
break;

В этом примере за 3 шага создаётся дерево из связанных клеток. Перед делением клетка проверяет значение s. Если оно меньше 3, клетка прибавляет к нему 1 и делится, передавая значение s потомкам. Так продолжается, пока s не станет равным 3.

apoptosis

Клетки можно так же легко уничтожать, как и делить, командой apoptosis.

Важно!: «apoptosis» и «split 1» работают как «break»: клетка не выполняет то, что написано после них. Поэтому, если клетка в любом случае делится или самоуничтожается, «break» в конце скрипта можно не ставить.

load и return

Если нужно повторить определённый код больше одного раза за обновление клетки, используйте load и return. Поставьте «load» в точку, куда хотите вернуться, а «return» в точку, откуда нужно вернуться к «load».

byte a 0;
load;
a a + 1;
if a < 99 {
  return;
}
red a;
break;

Хотя здесь написано «a a + 1», на деле за каждое обновление к a будет прибавляться 99, потому что «a a + 1» повторяется снова и снова, пока значение a не дойдёт до 99.

organelle

Когда вы разобрались со всеми основными частями виртуальной машины, можно усложнить само устройство клетки. Команда organelle создаёт у клетки работающие отростки. Указав тип (byte), угол (float) и силу (float), вы можете вырастить на нужном участке клетки нужную органеллу.

byte init 0;
if init == 0 {
  organelle 0 0.35 -0.004 0;
  organelle 0 -0.35 -0.004 1;
  red 30;
  green 180;
  blue 50;
  init 1;
}
break;

Как видно из примера, создаётся подобие хламидомонады.

Эмбриология и морфогены

Клетки могут передавать сигнал на расстояние в нужном вам радиусе.

Чтобы создать морфоген (сигнал с определённым радиусом), используйте команду diffusion в такой конфигурации:

diffusion <int> номер <float> радиус <float> скорость;

«скорость» это ослабление сигнала за каждый кадр.

Теперь, когда вы создали сигнал, вы можете получить информацию о дистанции, если клетка находится в его радиусе. Для этого обратитесь к рецепторам командой detect, записав результат в переменную в таком виде:

detect <int> номер морфогена, откуда берём <переменная> куда записываем;

Пример клеток, красящих себя в зависимости от дистанции:

byte t 0;
float c 0;
float tiny 0.05;
float low 1;
if t == 0 {
  diffusion 0 5 0.01;
}
t t + 1;
if t == 90 {
  t 0;
}
detect 0 c;
red 0;
green 0;
blue 255;
if tiny < c {
  red 0;
  green 255;
  blue 0;
}
if low < c {
  red 255;
  green 0;
  blue 0;
}
break;

Переменная для detect должна быть типа float, а сравнивать float можно только с другой переменной float, а не с числом, поэтому здесь есть tiny и low. Счётчик t нужен, чтобы морфоген создавался не каждый кадр, а раз в 90 кадров: сигнал живёт примерно 100 кадров.

Важно!: когда клетка не находится в радиусе морфогена, параметр, который вы можете получить через detect, медленно угасает по формуле «силаМорфогена *= 0.9». Когда клетка в зоне досягаемости морфогена, она получает от него сигнал «радиус / (дистанция + 1)».
