синтаксис
конец скрипта

Когда вы компилируете программу, компилятор проходится по всем командам и ставит пути, поэтому чтобы тот знал где остановиться, необходимо ставить break там, где дальше нет команд

[ваши команды]
break;
цвета

При создании клетка получает случайные цвета

Чтобы задать цвет клетке, вы можете использовать команды red green и blue + число от 0 до 255, это задаст цвет тому каналу, который вы выберете

red 255;
green 127;
blue 0;
break;

Это задаст цвет клетки с случайного на оранжевый

комментарии

Используйте квадратные скобки [ ], чтобы закомментировать часть кода

Всё, что находится внутри скобок, будет проигнорировано компилятором

[red 255]
[green 255]
blue 255; [только синий цвет будет ставиться на 255]
break;
деление

Клетка может делиться на 2, распределяя массу на 2 дочерние клетки, используя команду split в такой конфигурации:

  • первое значение <byte>:
    • 0 — деление без связи (клетки не будут соединены после деления)
    • 1 — деление со связью (клетки будут соединены связкой)
  • второе значение <float> — угол деления (направление, в котором разойдутся дочерние клетки)
split 0 0;
break;
split 1 0;
break;

Если нужно, чтобы клетки росли в разные стороны, как будто случайно, используйте псевдослучайный угол: при каждом делении прибавляйте к нему одно и то же число, например 2.4 (это золотой угол в радианах, около 137.5 градуса), и направления будут равномерно распределяться

float angle 0 heirdom 2;
if MASS > 9 {
  angle angle + 2.4; [новый угол при каждом делении]
  split 0 angle;
}
break;

Когда клетка использует split - процесс виртуальной машины завершается, и сразу запускается процесс деления (занимает некоторое время), поэтому команды после него не работают

red 63;
green 63;
blue 63;
split 0 0; [код после этой команды не будет работать, поэтому клетка будет тёмной, хотя дальше все цвета на 255:]
red 255;
green 255;
blue 255;
break;
математика
данные
типы

Есть 3 типа данных:

  • byte — весят 8 бит, могут хранить от -128 до 127 или от 0 до 255 целых чисел
  • int — весят 32 бит, могут хранить от -2147483648 до 2147483647 или от 0 до 4294967295 целых чисел
  • float — весят 32 бит, могут хранить от -16777216 до 16777215 или от 0 до 33554432 дробных чисел

Разные функции могут использовать разные типы данных

red, green и blue принимают byte, используя в формате от 0 до 255

создание

Вы можете создать переменную и менять её по своему усмотрению, во время работы виртуальной машины

инициализация

Чтобы создать данное, необходимо указать тип, название и значение

byte a 10; [это создаст число, которое может хранить 256 значений]
break;

Данное можно использовать для функционала

byte a 60;
byte b 120;
red a;
green a;
blue b;
break;
наследование

После деления клетка сбрасывает все значения на те, которые указаны при создании

byte a 10;
a 200;
split 0 0; [дочерние клетки до своих итераций будут хранить 'a' опять с числом 10]

Чтобы избежать этого, используйте модификатор heirdom + значение, которое укажет у какой клетки значение не сбросится

byte using 0 heirdom 0;
red using;
using using + 255;
split 0 0;

Какие числа что значат:

  • 0 — 1 клетка наследует значение
  • 1 — 2 клетка наследует значение
  • 2 — обе клетки наследуют значение
редактирование

Вы можете редактировать данные через операторы -, +, /, * и другие данные

byte a 100; [если что у данных может быть любое название, но нежелательно, чтобы оно совпадало с функцией или что-либо другое, связанное с кодом (условно "green" лучше не использовать)]
byte b 30;
byte c 70;
c a + b;
green c;
red c;
blue a;
break;

Можно использовать и более сложные вычисления

byte a 100;
byte b 30;
byte c 70;
c a - b * a + b * 23;
green c;
red c;
blue a;
break;

Можно менять цвет каждую итерацию

byte f 0;
f f + 1;
red f;
green f;
blue f;
break;
встроенные переменные

У клеток есть встроенные переменные, даже если они не объявлены в скрипте

Из них:

  • MASS — масса клетки
  • LINKS — количество связей с клетками (смежные клетки с физической связью)
  • PI — число пи, подойдёт для углов
логика
условие

Команда if использует условие, при выполнении которого может запустить определённый фрагмент кода в фигурных скобках, после условия

int a 1234;
int b 4268;
red 0;
green 0;
blue 0;
if a == 1234 { [если 'a' равняется 1234, то задаём красному 255]
  red 255;
}
if b == a { [если 'b' равняется 'a', то задаём синему 255]
  blue 255;
}
if b > a { [если 'b' больше 'a', задаём зелёному 255]
  green 255;
}
break;

всего есть такие операторы:

  • == — такое же ли
  • > — больше ли
  • < — меньше ли
  • != — не одно ли число
  • >= — больше или такое же
  • <= — меньше или такое же
циклы

Циклы возвращают в ту часть кода, где было написано load

Однако чтобы не попасть в бесконечный цикл, его рекомендуется использовать с условием/условиями

byte a 0;
load; [ставим точку возвращения]
if a < 255 {
  a a + 1;
  return; [возвращаемся если 'a' < 255]
}
red a; [клетка станет красной с 1 итерации, благодаря циклу]
green 0;
blue 0;
апоптоз

Клетка может самоуничтожиться через команду apoptosis

При этом это так же работает как и split - клетка не выполняет код после этой команды

apoptosis;
break;
органеллы

У клетки могут быть органы, влияющие на внешнюю среду

Для создания органеллы на поверхности клетки используйте команду organelle с такими входящими данными:

  • тип <byte>:
    • фаго <0> — притягивает (тратя на это массу) и поедает еду, попавшую в неё
    • деворо <1> — ворует массу у смежной клетки
    • жгут <2> — двигает клетку по своему направлению и тратит на это массу
  • угол <float> — угол относительно центра клетки
  • сила <float> — скорость работы и прочее, однако тратит массу в зависимости от числа
  • отзеркаливание <byte>:
    • 0 — обычно
    • 1 — зеркально отражена вдоль своего направления
byte init 0;
float angle 0 heirdom 2;
if init == 0 {
  organelle 0 0 0.005 0; [фаго органелла с 1 стороны]
  organelle 2 PI -0.005 1; [жгутик с другой стороны]
  init 1;
}
if MASS > 9 {
  angle angle + 2.4; [псевдослучайный угол деления]
  split 0 angle;
}
break;

Если вам удобнее задавать углы в градусах, вы можете использовать настройки компиляции через команды @radian и @float

@radian;
byte init 0;
float angle 0 heirdom 2;
if init == 0 {
  organelle 0 0 0.005 0; [фаго органелла с 1 стороны]
  organelle 2 180 -0.005 1; [жгутик с другой стороны, угол в градусах]
  init 1;
}
if MASS > 9 {
  angle angle + 137.5; [псевдослучайный угол деления]
  split 0 angle;
}
break;

Чтобы вернуть всё обратно, используйте @float

@radian;
@float;
byte init 0;
float angle 0 heirdom 2;
if init == 0 {
  organelle 0 0 0.005 0; [фаго органелла с 1 стороны]
  organelle 2 PI -0.005 1; [жгутик с другой стороны через PI, как до этого]
  init 1;
}
if MASS > 9 {
  angle angle + 2.4; [псевдослучайный угол деления]
  split 0 angle;
}
break;
онтогенез

Через морфоген возможно распространение сигнала на расстоянии, в радиусе

Чтобы подать сигнал используйте diffusion в таком виде:

  • номер <int> — то, какой номер будет у сигнала, для получения другой клеткой
  • радиус <float> — радиус распространения сигнала
  • диффузия <float> — скорость деградации сигнала за итерацию

Чтобы получить сигнал используйте detect:

  • номер <int> — тот сигнал, который будет проверять клетка
  • переменная <float> — та переменная, куда будет записываться сила сигнала (чем ближе источник, тем она больше)
byte t 0;
float c 0;
float tiny 0.05;
float low 1;
if t == 0 {
  diffusion 0 5 0.01; [излучение сигнала]
}
t t + 1;
if t == 90 {
  t 0;
}
detect 0 c;
red 0;
green 0;
blue 255;
if tiny < c { [если сигнал зафиксирован, издаёт зелёный]
  red 0;
  green 255;
  blue 0;
}
if low < c { [если сигнал близко, издаёт красный]
  red 255;
  green 0;
  blue 0;
}
break;
передача

Многоклеточные организмы могут передавать еду по связям между связанными клетками, через команду transfer в такой конфигурации:

  • сила <float> — то, с какой скоростью (или силой) будет передаваться масса
  • номер <int> — номер связи, по которой будет передаваться/забираться масса
byte splitable 0 heirdom 2;
byte transmission 0 heirdom 0;
if splitable == 0 {
  splitable 1;
  transmission 1;
  split 1 0;
}
if transmission == 0 {
  transfer 0.01 0; [передача с силой 0.01 по пути 0]
}
break;

Можно строить при помощи этого более сложные организмы, с клетками, которые будут делать разные функции, делая организм модульным

@radian;
byte a 0 heirdom 0;
byte b 0 heirdom 1;
byte c 0 heirdom 2;
if c == 0 {
  c 1;
  a 1;
  b 1;
  split 1 0;
}
if a == 1 {
  a 0;
  organelle 0 0 0.001 1;
}
if b == 1 {
  b 0;
  organelle 2 180 0.01 1;
}
if MASS < 5 {
  transfer 0.5 0;
}
break;

политика конфиденциальности

Проект: biochemistry — клеточная симуляция с редактором скриптов.
Дата последнего обновления: 8 ноября 2026.

Коротко: мы не собираем, не храним и не передаём ваши персональные данные. Всё, что вы создаёте в симуляции, остаётся на вашем устройстве.

1. Какие данные мы собираем

Никакие. В приложении нет регистрации, аккаунтов, рекламы и встроенной аналитики. Мы не знаем, кто вы, откуда вы и какие клетки вы запускаете.

2. Что хранится на вашем устройстве

  • скрипты клеток, которые вы пишете в редакторе;
  • настройки симуляции;
  • состояние самой симуляции.

Эти данные лежат только в памяти вашего устройства. Мы не имеем к ним доступа, а при удалении приложения они удаляются вместе с ним.

3. Доступ к устройству

Симуляция работает без интернета и не требует доступа к камере, микрофону, контактам, геолокации или личным файлам.

4. Письма разработчику

Если вы пишете о баге или ошибке на почту «biochemistrydev@gmail.com», мы увидим ваш адрес и текст письма. Мы используем их только чтобы ответить и исправить проблему, и не передаём третьим лицам. Хотите, чтобы переписку удалили — просто напишите об этом.

Скачать apk и исходный код, а также зайти в сообщество можно через Telegram. Это сторонний сервис со своей политикой конфиденциальности, и мы за неё не отвечаем. Всё, что вы пишете в сообществе, видят другие участники, так что не публикуйте там личные данные.

6. Дети

Мы не собираем данные ни о ком, в том числе о детях, потому что вообще ничего не собираем.
